# Development guidelines for all agents

- Build a fast, modern, maintainable landing page.
- Write clean, production-ready code.
- Keep components small and single-purpose.
- Reuse existing components before creating new ones.
- Avoid duplicating logic and keep files small.
- Prefer composition over inheritance.
- Use strict TypeScript; never use `any` unless absolutely necessary.
- Use semantic HTML and accessible elements.
- Use exactly one `h1` per page.
- Add `alt` text to all images.
- Ensure keyboard accessibility and usability.
- Optimize images and lazy-load non-critical assets.
- Minimize JavaScript and avoid unnecessary re-renders.
- Include title, meta description, and Open Graph tags.
- Follow a semantic heading structure.
- Use a color palette centered on `#4684C2` and `#E8AC67`.
- Buttons and interactive elements may use gentle gradients and subtle animations.
- Write mobile-first styles and keep CSS simple.
- Avoid inline styles unless justified.
- Before finishing, verify no TypeScript errors, lint issues, unused code, or `console.log` statements.
